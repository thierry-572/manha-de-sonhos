
# ☀️ Manhã de Sonhos

Um projeto de desenvolvimento web que busca transmitir leveza, criatividade e uma experiência visual agradável por meio de uma interface intuitiva.

## 📌 Sobre o projeto

O **Manhã de Sonhos** é um projeto desenvolvido para praticar e demonstrar conhecimentos em desenvolvimento web, explorando a construção de páginas, a organização de conteúdo e a estilização de interfaces.

O projeto faz parte do meu portfólio pessoal e representa minha evolução no desenvolvimento de aplicações web.

## 🎯 Objetivos

- Desenvolver uma interface visualmente agradável.
- Aplicar conceitos de estruturação de páginas web.
- Praticar estilização e organização de layouts.
- Aprimorar conhecimentos em desenvolvimento front-end.
- Construir projetos práticos para meu portfólio.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/thierry-572/manha-de-sonhos.git
```

Entre na pasta do projeto:

```bash
cd manha-de-sonhos
```

Abra o arquivo `index.html` no navegador.

## 📂 Estrutura do projeto

```text
manha-de-sonhos/
├── index.html
├── style.css
├── script.js
└── README.md
```


## 📚 Aprendizados

Este projeto contribui para o desenvolvimento de habilidades em HTML, CSS e JavaScript, além de proporcionar experiência prática na criação e organização de interfaces web.
